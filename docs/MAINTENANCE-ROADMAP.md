# Maintenance roadmap

This is a list of areas for real future work. It does not assign dates or imply that work is complete.

- Review spoken labels, focus order, high contrast, text scaling, and RTL layout with Linux users.
- Add locale coverage after translations can be reviewed by fluent humans.
- Improve CSV/HTML export options based on actual user needs.
- Expand date-engine boundary tests and keep the upstream calendrical dependency maintained.
- Refine month/year navigation and narrow-window behavior based on accessibility and usability reports.
- Keep Ubuntu CI, GTK, libadwaita, Snapcraft base, and relevant runtime compatibility current.
- Correct documentation when real user reports expose confusing calendar terminology.
- Triage public bug reports and release only reviewed, tested changes.

Do not add commits, issues, or releases solely to make the project appear older or busier.
