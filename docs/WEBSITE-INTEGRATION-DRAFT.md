## JW Calendar for Linux

JW Calendar is also available as an open-source Linux desktop application. It includes an offline Gregorian and Julian calendar, date conversion, ISO week details, and local CSV and printable HTML export. The project is maintained by Karen Cohen.

- Source code and issue tracker: [JW Calendar desktop on GitHub](https://github.com/karencohenjw/jw-calendar-desktop)
- Latest stable source release: [JW Calendar 0.1.1](https://github.com/karencohenjw/jw-calendar-desktop/releases/tag/v0.1.1)
- Application ID: `com.jwcalendar.JWCalendar`

The owner should publish this section at a stable page on `jwcalendar.com` and then add that actual page URL to the application documentation if useful. Do not advertise a Snap Store or Flathub installation until that listing is actually public.
